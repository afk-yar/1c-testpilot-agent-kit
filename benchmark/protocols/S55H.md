## Проблемы инструмента
- `add_rows` / `set_cell_text` на колонку "Цена" при заполненном "Price type": invalid_element_state / column_focus_redirected без объяснения, что причина - заполненный вид цены. Чинится очисткой ТоварыВидЦены (set_cell_text с пустым text -> "<custom>"). Диагностика не указывает причину.
- После `input_text` в поле ссылочного типа с несуществующим значением ввод остается pending (committed false), и следующий `add_rows` в другой таблице отказывает `input_pending`; сброс - `activate` на другое поле. Хотя выбор через форму выбора (`choose_row`) закрыл pending неявно, флаг в инструменте остался.
- `find_rows`/`read_rows` в форме выбора партнера не видят строку "Тест Клиент" (rows_checked 0 / row_count 1), хотя она на экране; `goto_row` + `choose_row` работают.
- `set_cell_text` для колонки-перечисления ("Actions"): unsupported_element_type; нужен обход change_row + activate + get_choice_list + execute_choice_from_choice_list (параметр `value`, в схеме не очевиден: `text` не принимается).
- `execute_choice_from_choice_list` вернул `value_after: null` / `changed: null`, а затем `end_edit_row` отказал `active_window_changed`: инструмент не сообщает о появившемся вопросе конфигурации ("Select action"), пришлось смотреть `get_active_window` вручную.
- `get_current_element` (tc_form) не показывает текущую колонку таблицы, только саму таблицу; `tc_form` принимает только ref ManagedForm, а не ref окна (ref окна и формы разные).
- `get_user_message_texts` после успешного проведения возвращает `user_messages_unavailable` (панель закрыта) - неотличимо от отсутствия сообщений.
- `delete_row` возвращает `deleted: null`, `deletion_status: requested` - результат приходится проверять `read_rows`.
- `find_objects` без фильтров по кнопкам формы возвращает ~95 элементов (дорого по контексту); `cls=CommandButton` не существует (класс `Button`).
